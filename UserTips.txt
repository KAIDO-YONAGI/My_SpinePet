SpinePet 桌宠使用说明
====================

（English version: UserTips.en.txt）

【启动与退出】
- 发布包请双击 Launch.bat，或直接运行 app\SpinePet.exe。
- 双击托盘图标，或在托盘菜单选择 Open Panel，可打开配置面板。
- Finish Configuration、Alt+F4 或关闭窗口会保存设置并隐藏面板，不会退出桌宠。
- 托盘菜单还提供 Show All、Hide All 和 Exit。
- 紧急退出快捷键：Ctrl+Alt+Shift+F12。

【桌面角色】
- 左键单击：播放角色的点击动画；没有匹配动画时保持当前动画。
- 按住左键拖动：移动角色并保存位置，需要开启 Allow dragging in render mode。
- 右键角色：
  · 面板关闭时，打开配置并自动选中、滚动到该角色的左侧条目。
  · 面板已打开时，保存并关闭配置面板。

【左侧角色库】
- 点击角色卡片：选中角色并在右侧显示详情。
- Show / Hide：切换角色显隐，同时把右侧详情切换到该角色，但不会强制滚动列表。
- Position：恢复该角色的默认位置，同时切换右侧详情，但不会强制滚动列表。
- 白色 Show/Hide 按钮表示角色当前已显示；Loading 时暂时不能重复操作。
- 滚动列表时，右侧详情会按两列顺序跟随视口中央的角色。
- 搜索支持角色名和 Skin 信息。Ctrl+F 聚焦，Down/Enter 进入结果，Esc 清空。
- 方向键选择角色；Enter/Space 切换显隐；右键卡片或 Shift+F10 可切换 Skin。
- 预览尺寸滑条可在 50%–150% 之间调整角色卡片大小。

【右侧设置】
- Animation：选择并循环播放角色动画。
- Desktop frame rate：30 / 60 / 120 FPS，全局生效。
- Allow dragging in render mode：控制所有桌面角色能否拖动，全局生效。
- Scale：
  · 第一条是基础比例 0%–100%，100% 对应基础缩放 0.2。
  · 第二条是独立的 1.0–5.0 倍乘数，不会改动第一条。
  · 最终缩放 = 基础比例 ÷ 100 × 0.2 × 倍率，并受角色最大尺寸限制。
  · Reset 恢复 100% 和 1.0 倍。
- Animation Speed：0.10–2.00 倍；Reset 恢复 1.00 倍。
- Delete Current Skin：确认后把当前 Skin 目录移入 Windows 回收站。

【添加与管理资源】
- 支持四类资源：待机 standing、射击 aim/cover（成对，用 battle-catalog-importer 导入）、
  爆裂 skillcut（目录名以 " Burst" 结尾）、珍藏品 Favorite（编号固定 9NNN、皮肤 00，不进 Battle）。
- 游戏导出的原始资源需要先改目录名与 c<角色ID>_<皮肤ID> 文件名才能导入；
  四类资源的完整规范、工具用法与排查清单见包内 IMPORT.md。
- Add：导入 .skel 或符合命名规则的 UnityFS bundle。
- Scan：重新扫描 res，同步手动添加、删除或替换的资源。
- Folder：打开当前使用的 res 目录；目录不存在时会自动创建。
- 手动放入资源时使用以下结构，Skin 编号缺省时可使用 00：
    res\<角色名>\<Skin编号>\standing\<资源名>.skel
    res\<角色名>\<Skin编号>\standing\<资源名>.atlas
    res\<角色名>\<Skin编号>\standing\<资源名>.png
    res\<角色名>\<Skin编号>\icons\<资源名>_icon.png
- 图标是可选项；放入资源后点击 Scan 即可刷新角色库。

【发布包目录】
- Launch.bat：推荐启动入口。
- config.json：便携配置，保存角色、显隐、位置、缩放、动画、速度和全局设置。
- res\：角色资源库。发布包内**不含**任何资源，只放了一份放置说明；
  把资源放进去后点 Scan 即可（见下一节）。
- app\：程序本体，请勿改名。
- tools\：运行时工具（UnityFS 解包脚本、图标下载脚本、requirements.txt），请勿改名或删除。
- Logs\：运行后生成的日志目录，用于排查问题。
- LICENSE / NOTICE：本项目的开源许可证（GPL-3.0-or-later）与版权声明。
- THIRD_PARTY_NOTICES.md：第三方组件与授权清单。
- ASSETS.md：素材来源与授权边界说明。
- licenses\：各第三方许可证原文，请勿删除。
- IMPORT.md / IMPORT.en.md：素材导入指南（四类资源、格式改造、工具、AI 辅助、排查）。
- Check-Environment.ps1：运行环境自检。在包内执行
    powershell -NoProfile -ExecutionPolicy Bypass -File Check-Environment.ps1
  它会列出缺什么、以及缺了会损失哪个功能（例如没装 Python 就不能用 UnityFS bundle 导入）。

【窗口与多实例】
- 配置窗口无边框，拖动空白区域可移动窗口，拖动边缘可调整大小。
- 同一目录的程序重复启动时会激活已有实例。
- 不同构建目录的 EXE 使用独立实例，可以同时运行。

【卸载】
- 便携发布包可直接删除整个文件夹；配置、资源和日志均保存在包内。
